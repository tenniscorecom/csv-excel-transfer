# csv-excel-transfer の使い方

`config.ini.example` を基に `config.ini` を作り、入力・出力フォルダとファイル名、
転記する列を設定します。西・東 CSV と INPUT Excel を指定フォルダへ置き、`実行.bat` を
実行してください。

出力は `OUTPUT_EXCEL_FOLDER` に「`OUTPUT_PREFIX` + `INPUT_NAME`」の名前で作られます。
成功時だけ元の CSV 2本と INPUT Excel が削除されます。失敗時は入力が残るため、表示された
エラーを直して再実行してください。

`READ_PASSWORD` はExcelを開くときのパスワード、`WRITE_PASSWORD` は編集するときの
パスワードです。不要な方は空欄にします。パスワードを設定した保存にはExcel本体が必要です。

現在の通常起動は安全確認用のdry-runです。本番運用へ切り替える際は、入力3ファイルが
出力成功後に削除されることを確認したうえで、管理者が `main.py` の
`with dry_run(), debug():` を外してください。事前確認には `python smoke_test.py` を使えます。
