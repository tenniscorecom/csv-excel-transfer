# 使い方

このツールの操作手順（実行する人向け）。エンジニアでなくてもこのページだけ読めば使えるようにする。

---

## このツールは何をするもの？

西日本の顧客CSVと東日本の顧客CSVを **1つの顧客マスタ** としてまとめ、
INPUT エクセルの「業務用ID」列をキーに、**指定した列だけ**を Excel へ転記するツールです。

成功すると、次の3つのファイルが **同じフォルダ** に生まれ変わります:

| 種類 | 例 |
|---|---|
| 入力 | 西CSV・東CSV・作業対象.xlsx |
| 出力 | **最終_**作業対象.xlsx（同じフォルダに作られる） |
| 削除 | 西CSV・東CSV・作業対象.xlsx（保存が成功したら自動で消える） |

---

## 初回だけやること（1回でOK）

1. **`実行.bat` を1度動かす**（または `python main.py` を実行する）。`config.ini.example` から `config.ini` が作られて止まるので、
   中を開いて、次の3つのセクションの値を自分の環境に合わせて書き換える
   - `[FILES] WEST_CSV / EAST_CSV / INPUT_XLSX`：3つのファイルパス
   - `[EXCEL] SHEET`：転記対象シート
   - `[転記_MAPPING]`：CSV の列名（左）→ INPUT エクセルの列名（右）

2. **パスワードを付ける場合**は `[EXCEL] PASSWORD` に値を書く。
   **付けない場合は空欄のまま**にしておく（推奨）。

   - パスワード値は **config.ini に直接書くのではなく**、管理者が決めた共有方法に従ってください（社内ルールに従う）
   - 動作確認用にダミーの値を入れて試すのは問題ありません

---

## 毎回の使い方

1. 西CSV・東CSV・作業対象.xlsx の3つを、**config.ini で指定したパスに置く**
2. ターミナルで `実行.bat` を叩く（または `python main.py` を実行する）
3. 黒い画面にログが流れる。**正常なら**「最終_作業対象.xlsx」ができて、元3ファイルが消える
4. `実行.bat` は `pause` を入れないので、画面は一瞬で閉じる（エラーならエラーコードが返る）

---

## 本番前に「何をするか」を確かめたい

`config.ini` の `[RUN] DRY_RUN = True` にして1度動かす。
ファイルは **作られず・消されず**、ログに「[DRY-RUN] …」と「何をする予定だったか」が出ます。
問題なければ `DRY_RUN = False` に戻して本番実行。

> **True のまま戻し忘れると**、毎日成功しているのに何も出力されない状態になります。
> 終了コードも 0 なのでスケジューラは気づけません。**戻し忘れに注意。**

---

## うまくいかないとき

- 黒い画面に赤い英語（エラー名）が出たら、**[ERRORS.md](ERRORS.md)** でその名前を探して対処する
- 西CSV と 東CSV の両方に同じお客様IDがあると止まります（**`CustomerIdDuplicateAcrossCsvError`**）。
  どちらを採用するか業務ルールで決めてから再実行する
- INPUT エクセルのシート名・列名を [EXCEL] / [転記_MAPPING] と実物が一致しているか確認する
- パスワード付き保存時、**Excel がインストールされていない PC では `ExcelApplicationNotAvailableError` で止まります**。
  パスワードを付けない運用に切り替えるか、Excel が使える PC で実行する
- 解決しないときは、**画面全体をスクリーンショット**して管理者に送る

## よくある質問

**Q. 出力ファイルはどこ？**
A. `config.ini [FILES] INPUT_XLSX` と同じフォルダに「最終_ + 元のファイル名」で作られます。

**Q. 元のCSVやExcelは消える？**
A. 最終ファイルの保存が**成功した場合だけ**自動で消えます。途中で失敗したら消えません（再実行できます）。

**Q. パスワードは何を書けばいい？**
A. 管理者から共有されたパスワードをそのまま `[EXCEL] PASSWORD` に書きます。空欄ならパスワードなしで保存されます。

**Q. 同じお客様IDが西と東の両方にあったら？**
A. 例外で停止します（[ERRORS.md](ERRORS.md) 参照）。どちらか片方に寄せてから再実行してください。

## Excel がインストールされた PC での初回手動確認（1回だけ）

パスワード付き保存の経路（`[EXCEL] PASSWORD` に値を書いたとき）は、
**Excel がインストールされた PC でのみ**正しく動きます。Excel が無い開発用の
PC では自動テストで代替しているので、**会社の PC へ持ち込んだ最初の 1 回だけ**、
下のチェックリストで動作を目視確認してください。

確認には3つのテスト用ファイル（西CSV・東CSV・作業対象.xlsx）が要ります。
雛形が同じフォルダに置いてあるはずなので、無ければ管理者に用意してもらってください。

### 手順

1. `config.ini` の `[EXCEL] PASSWORD` にダミー値（例: `test1234`）を入れる
2. `[RUN] DRY_RUN = True` にして **1度** `実行.bat` を叩く
   - ログに「パスワード付きで最終ファイルを保存する予定」と「ファイル名」「転記予定件数」が出ること
   - **ファイルが1つも作られていないこと**（DRY-RUN では作らないため）
4. `[RUN] DRY_RUN = False` に戻して、もう一度 `実行.bat` を叩く
5. 黒い画面の終了後に、3つのテスト用ファイルが置いてあるフォルダを開く
   - 「**最終_**作業対象.xlsx」が **新しいファイル**として出来ていること
   - そのファイルを **ダブルクリックで開く**と、**パスワード入力ダイアログ**が出ること
   - パスワード欄に手順1で設定した値を入れて開けること
   - 中身を見て、CSV のお名前・ご住所・電話番号が転記されていること
6. **同じフォルダから元の3ファイル（西CSV・東CSV・作業対象.xlsx）が消えていること**
   - **消えていない場合は**そのままにせず、管理者に連絡する（削除処理が壊れている可能性）

### 確認できたら

- `[EXCEL] PASSWORD` を **本番用に管理者から共有された値**に書き換える
  （確認用のダミー値のままだと本人都が開けないファイルになります）
- テスト用ファイルは不要なので削除してよい

### うまくいかないとき

- 手順3で **「DRY-RUN 中も COM は起動しません」** のようなエラーが出たら、
  `[EXCEL] PASSWORD` が空欄になっていないか確認する（空欄だと別経路で動くため確認にならない）
- 手順5で **パスワード入力が出ない**場合は COM が失敗している可能性が高い。
  Excel がインストールされているか、開いている Excel を全部閉じてから再実行する
- 手順5で **「最終_作業対象.xlsx」が出来ない / 開けない**場合は
  `[ERRORS.md](ERRORS.md)` の `OutputFileMissingError` / `SourceFileDeletionError` を参照する
